Que contient exactement le module Compilation ?

Le module Compilation contient le cours complet en PDF, les TD et exercices corrigés, les examens des sessions précédentes avec corrections détaillées, et selon le module des TP ou fiches de révision. Tous les fichiers sont rangés dans des sous-dossiers clairs sur Google Drive : Cours / TD / Examens / TP.

Comment télécharger le module Compilation ?

Cliquez sur le bouton de commande, sélectionnez Compilation dans le catalogue, renseignez votre email, payez {{ site.module_price }}$ via PayPal, et vous êtes redirigé immédiatement vers votre Google Drive. Le lien est également envoyé par email pour un accès permanent.
