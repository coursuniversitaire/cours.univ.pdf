Le module Recherche opérationnelle contient le cours complet en PDF, les TD et exercices corrigés, les examens des sessions précédentes avec corrections détaillées, et selon le module des TP ou fiches de révision. Tous les fichiers sont rangés dans des sous-dossiers clairs sur Google Drive : Cours / TD / Examens / TP.

Cliquez sur le bouton de commande, sélectionnez Recherche opérationnelle dans le catalogue, renseignez votre email, payez 0,5$ via PayPal, et vous êtes redirigé immédiatement vers votre Google Drive. Le lien est également envoyé par email pour un accès permanent.
