Le module Développement d'applications réparties contient le cours complet en PDF, les TD et exercices corrigés, les examens des sessions précédentes avec corrections détaillées, et selon le module des TP ou fiches de révision. Comment télécharger le module Développement d'applications réparties ?

Cliquez sur le bouton de commande, sélectionnez Développement d'applications réparties dans le catalogue, renseignez votre email, payez 0,5$ via PayPal, et vous êtes redirigé immédiatement vers votre Google Drive. Le lien est également envoyé par email pour un accès permanent.
